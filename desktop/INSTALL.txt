Domeo — просчёт спецификаций. Как установить

1. Распакуйте этот архив в любую папку (например, прямо на «Рабочий стол»).
   Отдельная установка не нужна.

2. Откройте папку и запустите файл  Domeo.exe
   Ярлык можно вынести на рабочий стол: правый клик по Domeo.exe →
   «Отправить» → «Рабочий стол (создать ярлык)».

3. При первом запуске Windows может показать синее окно
   «Система Windows защитила ваш компьютер».
   Нажмите «Подробнее» → «Выполнить в любом случае».
   Приложение без цифровой подписи — это нормально.

4. Первый запуск идёт дольше обычного (30–60 секунд): настраивается
   встроенная база данных. Затем откроется окно программы.

Больше ничего ставить не нужно — Python, .NET, PostgreSQL и распознавание
сканов (OCR) уже внутри. Папку с программой можно перемещать и
переименовывать как угодно, в том числе с русскими буквами в пути.

Данные (история КП, объекты, кэш цен) хранятся отдельно от программы и
сохраняются при её обновлении или перемещении.

Если вместо окна появилось сообщение про «Microsoft Edge WebView2 Runtime» —
установите этот бесплатный компонент Microsoft по ссылке из сообщения, затем
запустите Domeo снова. На Windows 11 он обычно уже установлен.
