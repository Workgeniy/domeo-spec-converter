Domeo — просчёт спецификаций

=== УСТАНОВКА (первый раз) ===

1. Распакуйте архив: правый клик по нему → «Извлечь всё…».
   Получится папка с программой — положите её куда удобно (можно на «Рабочий стол»).
   Отдельная установка не нужна.

2. Откройте папку и запустите файл  Domeo.exe
   Ярлык удобно вынести на рабочий стол: правый клик по Domeo.exe →
   «Отправить» → «Рабочий стол (создать ярлык)».

3. Если Windows покажет синее окно «Система Windows защитила ваш компьютер» —
   нажмите «Подробнее» → «Выполнить в любом случае».
   Приложение без цифровой подписи — это нормально.

4. Первый запуск идёт 30–60 секунд (настраивается встроенная база),
   затем откроется окно программы.

Ставить Python, .NET, PostgreSQL и OCR не нужно — всё уже внутри.
Права администратора не нужны. Путь может быть с русскими буквами.


=== ОБНОВЛЕНИЕ (пришла новая версия) ===

1. Закройте Domeo, если он открыт.
2. Удалите старую папку с программой (или переименуйте, например, в Domeo-old).
3. Распакуйте новый архив на её место и запустите Domeo.exe.

Важно: история КП, объекты и кэш цен НЕ потеряются — они хранятся отдельно от
программы и автоматически подхватятся новой версией. Папку с программой можно
смело удалять и заменять целиком.

При первом запуске этой версии может один раз появиться надпись «Перенос базы в
новый формат» — программа переводит историю и объекты на встроенное хранилище
(больше не нужен отдельный сервер базы данных). Это происходит один раз и занимает
несколько секунд; старые данные при этом сохраняются как резервная копия.


=== ЕСЛИ ЗАПУСКАЕТСЯ МЕДЛЕННО ===

Первый запуск и первый запуск после обновления идут дольше обычного: Защитник Windows
проверяет новые файлы программы. Чтобы запускалось за несколько секунд, один раз добавьте
папку с программой в исключения Защитника (нужны права администратора):

«Пуск» → «Безопасность Windows» → «Защита от вирусов и угроз» → «Управление настройками»
→ «Добавление или удаление исключений» → «Добавить исключение» → «Папка» → выберите папку,
где лежит Domeo.exe.

Если программа уже открыта, второй запуск её не откроет (чтобы не было двух копий) —
переключитесь на уже открытое окно.


=== ЕСЛИ ВМЕСТО ОКНА — СООБЩЕНИЕ ПРО WebView2 ===

Установите бесплатный компонент «Microsoft Edge WebView2 Runtime» по ссылке из
сообщения, затем запустите Domeo снова. На Windows 11 он обычно уже установлен.
