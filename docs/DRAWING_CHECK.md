# Минимальная сверка с планом

Вкладка «Сверка с планом»: загрузить PDF до 25 МБ, явно указать от 1 до 20 страниц через запятую
и нажать «Сверить со списком товаров». Список берётся из текущего свода всех томов,
с учётом правок и исключённых строк. Файл на сервере не сохраняется, модель и платные API
не используются. Страницы читаются последовательно, без растеризации и OCR.
Ядро принимает одну сверку за раз; параллельный запрос получает сообщение занятости.

Python извлекает строки текстового слоя и координаты. Таблицы спецификации пропускаются;
страницы без текста отмечаются как непроверенные. ASP.NET Core сопоставляет самостоятельные
подписи вида `2.10`, `Поз. 2.10`, `2,10 = 6` со значением позиции из свода.
Одна подпись считается одной единицей; `=6` — шестью. Разделитель позиции запятая
нормализуется в точку. Координаты — пункты PDF от левого верхнего угла отображаемой страницы.

Количество сравнивается только для единиц «шт.», «шт», «штука», «штуки», «штук».
Номера, повторяющиеся в списке товаров, помечаются неоднозначными: система не назначает
метки тому или помещению автоматически. Неизвестные подписи выводятся отдельно;
они могут оказаться номерами помещений или размерами, а не пропущенным товаром.

Результат предварительный: количество текстовых меток не гарантирует количество
нарисованных изделий. Не распознаются символы оборудования, контуры помещений,
планы-сканы, выноски между разными строками и сложные групповые обозначения.
Если все страницы пропущены, позиции помечаются «Страницы не прочитаны».
Если свод изменился после проверки, появляется предложение повторить сверку.
Результат находится в памяти вкладки и сбрасывается при уходе с неё; экспорт отчёта
и сохранение истории проверок в этот минимальный этап не входят.

API: `POST /api/specifications/check-drawing`, multipart `file` (PDF), `pages` (например `1,2`),
`items` (JSON-массив с `pos`, `name`, `qty`, `unit`). Ответ — `ApiResponse<DrawingCheckResult>`:
`rows` с ожидаемым количеством, найденными метками, статусом и координатами;
`unknown_labels` и `warnings`. Внутренний порт ядра: `POST /api/drawing-text`.

Дополнительные пакеты, сервисы и контейнеры не требуются. Потребление памяти на реальных
планах и при одновременной нагрузке stage пока не измерялось.
