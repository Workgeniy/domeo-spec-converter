# Выбор шаблона КП

Во вкладке «Формирование КП» доступен выбор стандартной формы или собственного
Excel-шаблона. Кнопка «Загрузить шаблон» добавляет XLSX (до 2 МБ), проверяет его
экспортом на одной позиции и выбирает после успешной проверки. Можно хранить несколько
шаблонов, переключаться между ними и удалять ненужные. Шаблоны и выбор сохраняются
в браузере отдельно от объекта; закрытие объекта их не удаляет. При заполнении хранилища
приложение показывает ошибку сохранения.

При загрузке исходной Excel-спецификации файл автоматически сохраняется в IndexedDB
браузера и связывается с томом объекта. Его можно скачать кнопкой «Скачать исходник».
Если XLSX соответствует требованиям формы КП, он также добавляется в список шаблонов;
первая подходящая форма при открытии нового объекта выбирается автоматически.
Добавление томов не переключает уже выбранную форму. В блоке шаблонов доступна кнопка
«Использовать для КП» для каждого подходящего исходника. Неподходящая форма сохраняется
как исходник с объяснением ограничения. Удаление тома или закрытие объекта удаляет его
исходник из IndexedDB; проверенные шаблоны остаются в общей библиотеке.
Файлы, загруженные до этой функции, нужно выбрать повторно: их байты раньше не сохранялись.

## Поддерживаемая форма

- Одна таблица для всех позиций или две таблицы: с графой «Цена за ед. СМР, с НДС»
  и без неё. Другие листы книги сохраняются.
  В единой таблице без отдельной графы СМР монтаж отмеченных позиций включается в цену.
- Шапка в первых 60 строках; обязательные графы «Наименование», «Кол во»
  (или «Количество»), «Цена за ед. товара, с НДС» либо «Цена за ед. товара (вкл. СМР), с НДС».
- Остальные графы распознаются по заголовкам стандартных приложений. Их порядок может
  отличаться. Если для формулы нет необходимых граф, рассчитанная величина записывается числом.
- Между шапкой и строкой «Итого»/«Всего» нужна хотя бы одна строка-образец товара.
  Её оформление копируется на новые позиции. Объединения внутри строк товаров
  не поддерживаются и вызывают понятную ошибку.
- Строки старых товаров заменяются, итоги и весь подвал перемещаются под новые позиции.
  Сохраняются названия и порядок листов, шапки, подписи, стили, ширины и скрытие столбцов,
  объединения вне товаров, настройки печати. Область печати и диапазоны итогов обновляются.
- Формат XLSM и макросы не поддерживаются. Используйте XLSX.

В тексте можно использовать `{{contract_number}}`, `{{contract_date}}`, `{{title}}`,
`{{supplier_position}}`, `{{customer_position}}`. При выгрузке они заменяются параметрами
КП. Номер и дата также подставляются в обычную шапку «Приложение … к Договору …»;
остальные тексты исходного шаблона сохраняются.

## Контракт

`POST /api/specifications/export` принимает дополнительное необязательное поле
`kp_template` — содержимое XLSX в base64. Оно используется только для выгрузки `kp`
при наличии `kp`. При отсутствии поля действует прежний экспорт. Ядро проверяет форму,
обрабатывает её в памяти и возвращает XLSX; файл шаблона на сервере не сохраняется.
Ошибки формы возвращаются как 422. Рабочая выгрузка и себестоимость не используют шаблон.
