# План

Конвейер «PDF → спецификация → цены → КП» из пяти шагов (по постановке заказчика):

1. Конвертировать спецификацию из PDF в редактируемый Excel.
2. Сверить спецификацию с чертежами (текст с графикой).
3. Подобрать по каждой позиции уточняющие параметры из внутренней базы (1С).
4. Найти стоимость позиции «от–до»: в базе и открытых источниках.
5. Проставить предполагаемую стоимость в столбец напротив позиции.

## Этап 2 — сверка с чертежами (шаг 2)

Метки позиций на планах лежат в PDF текстом с координатами (в ТХ1: 384/452/345 меток
на 1/2/3 этаже). Нужно: привязать метки к помещениям по экспликации, посчитать по
помещениям, сравнить с количеством в спецификации, разобрать сноски «=6», «25шт».
Результат — лист «Расхождения». Для сканов планов — только после OCR планов, качество
ниже.

## Этап 3 — цены из открытых источников (шаг 4, часть)

Сначала пищеблок (есть марки «по типу Polair CM107-S»), затем мебель по описанию.
Диапазон «от–до» со ссылками, кэш найденных цен с датой.

## Этап 4 — база 1С (шаги 3 и 4 полностью)

Начинается после выгрузки номенклатуры. Первое действие — оценка: какая доля позиций
вообще есть в базе. Интеграция: выгрузка в файл по расписанию (старт) → OData/HTTP-сервис
(позже). Копия номенклатуры с поисковым индексом на стороне сервиса; LLM сравнивает
характеристики кандидатов.

## Этап 5 — продукт

Шаблон КП заказчика, правила выбора цены из диапазона и наценки, сохранение правок
менеджера как эталонов, запись результата в 1С.

## Открытые вопросы к заказчику

1. 3–5 других проектов (разные проектировщики, есть ли сканы) — для проверки разбора.
2. Как считают сейчас: кто, сколько времени, сколько проектов в месяц.
3. Пример готового КП по уже просчитанному проекту (эталон для проверки).
4. Конфигурация 1С, как заведена номенклатура, какие цены хранятся, кто администрирует.
5. Правило выбора цены из диапазона, наценки, НДС, доставка/монтаж.
