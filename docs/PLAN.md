# План

Конвейер «PDF → спецификация → цены → КП» из пяти шагов (по постановке заказчика):

1. Конвертировать спецификацию из PDF в редактируемый Excel.
2. Сверить спецификацию с чертежами (текст с графикой).
3. Подобрать по каждой позиции уточняющие параметры из внутренней базы (1С).
4. Найти стоимость позиции «от–до»: в базе и открытых источниках.
5. Проставить предполагаемую стоимость в столбец напротив позиции.

## Этап 3 — себестоимость: три цены на позицию (шаги 3–4, уточнение заказчика 25.09.2026)

Заказчик уточнил схему: после конвертации получается не КП, а **файл себестоимости для
Домео** — спецификация с тремя ценовыми столбцами на каждую позицию, оператор выбирает,
какую цену взять; КП делается уже из него.

| Столбец | Откуда |
|---|---|
| Цена интернет на дату | ИИ находит, где продаётся, и ставит цену на сегодня (веб-поиск) |
| Цена минимальная по истории закупок | из прайса закупки, собранного по истории |
| Цена максимальная по истории закупок | то же |

**История закупок** — файл заказчика за много лет, одни и те же позиции повторяются с
разными ценами. Его надо один раз обработать ИИ: нормализовать наименования, собрать
**прайс закупки с эталонами** (позиция → характеристики, мин/макс цена, даты, поставщики).
Если позиции спецификации в истории нет — подобрать **аналог** по истории и прикрепить к
строке характеристики аналога (чтобы оператор видел, с чем сравнивают).

Порядок работ:
1. ✅ Файл истории получен («База_для_ИИ_заполнено_обезличено.xlsx», выгрузка 1С «Заказы
   поставщикам», 28 тыс. строк). Прайс закупки собирается в ядре: нормализация
   наименований, наборы → цена комплекта, выбросы отсечены; загрузка выгрузки через
   интерфейс, хранение на сервере (том `/data`).
2. ✅ Сопоставление по словам: точное → похожее (≥0.6) → аналог (≥0.3, с пометкой);
   кандидаты и последние покупки видны оператору. На трёх образцах покрытие
   точное+похожее ≈ 90 % позиций. ⏳ Подбор аналога по характеристикам через модель —
   после ответа заказчика, что считать аналогом.
3. ✅ Цена с рынка на дату, бесплатный путь (решение заказчика 25.09.2026: задача —
   «проверка цен на рынке», платных сервисов не надо): индекс каталогов поставщиков —
   обход сайтов (фид YML / карта сайта / ссылки, цена из разметки) и прайс-листы xlsx,
   сопоставление позиций с индексом, до 6 предложений с совпадением в процентах и
   медиана. ✅ Автопоиск (просьба пользователя 25.09.2026 «чтобы по поставщикам
   автоматически искал»): позиция без совпадения в индексе ищется бесплатным поисковиком
   (ddgs), найденные магазины сами становятся поставщиками и обходятся в фоне; поиск
   запускается автоматически при открытии вкладки. ⏳ После первых реальных объектов
   проверить долю позиций с ценой и качество магазинов из выдачи, подкрутить пороги и
   список пропускаемых сайтов; список проверенных поставщиков от заказчика ускорит дело.
   ✅ Платный путь оставлен как вариант: модель с веб-поиском (Claude, `web_search`),
   включается ключом `ANTHROPIC_API_KEY`; ориентир 10–15 ₽ на позицию (см. README), на
   реальных позициях с ключом не гоняли.
4. ✅ Интерфейс: вкладка «Себестоимость» — три ценовых графы, выбор по позиции щелчком и
   массово («везде минимум / медиану / максимум / последнюю»), выгрузка **«Себестоимость»**
   (лист с тремя ценами и выбранной + лист «Покупки по истории»), КП — из выбранной цены.

Нужно от заказчика: список поставщиков (сайты) и/или их прайс-листы xlsx; пример файла
себестоимости, если он уже ведётся; что считать аналогом.
