# План

Конвейер «PDF → спецификация → цены → КП» из пяти шагов (по постановке заказчика):

1. Конвертировать спецификацию из PDF в редактируемый Excel.
2. Сверить спецификацию с чертежами (текст с графикой).
3. Подобрать по каждой позиции уточняющие параметры из внутренней базы (1С).
4. Найти стоимость позиции «от–до»: в базе и открытых источниках.
5. Проставить предполагаемую стоимость в столбец напротив позиции.

## Этап 3 — себестоимость: три цены на позицию (шаги 3–4, уточнение заказчика 25.09.2026)

Заказчик уточнил схему: после конвертации получается не КП, а **файл себестоимости для
Домео** — спецификация с тремя ценовыми столбцами на каждую позицию, оператор выбирает,
какую цену взять; КП делается уже из него.

| Столбец | Откуда |
|---|---|
| Цена интернет на дату | ИИ находит, где продаётся, и ставит цену на сегодня (веб-поиск) |
| Цена минимальная по истории закупок | из прайса закупки, собранного по истории |
| Цена максимальная по истории закупок | то же |

**История закупок** — файл заказчика за много лет, одни и те же позиции повторяются с
разными ценами. Его надо один раз обработать ИИ: нормализовать наименования, собрать
**прайс закупки с эталонами** (позиция → характеристики, мин/макс цена, даты, поставщики).
Если позиции спецификации в истории нет — подобрать **аналог** по истории и прикрепить к
строке характеристики аналога (чтобы оператор видел, с чем сравнивают).

Порядок работ:
1. Получить файл истории закупок, посмотреть структуру и качество → «прайс закупки»
   (нормализация + дедупликация; ИИ там, где названия разнобойные).
2. Сопоставление позиций спецификации с прайсом: точное → по характеристикам → аналог
   с пометкой и характеристиками; уверенность на каждой строке.
3. Цена из интернета на дату: поиск по марке (пищеблок) или описанию (мебель), источник и
   дата у каждой цены, кэш.
4. Интерфейс: три ценовых столбца + выбор оператора (по позиции; массово «взять минимум /
   интернет»), выгрузка **«Себестоимость»** (внутренняя), КП — из выбранной цены как сейчас.

Нужно от заказчика: файл истории закупок (хотя бы фрагмент), пример файла себестоимости,
если он уже ведётся; решение по веб-поиску (какие сайты/маркетплейсы считать источником).

4. Конфигурация 1С, как заведена номенклатура, какие цены хранятся, кто администрирует.
5. Правило выбора цены из диапазона, наценки, НДС, доставка/монтаж.
