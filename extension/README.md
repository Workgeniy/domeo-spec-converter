# Domeo — расширение «цены для спецификации»

Каркас браузерного расширения (Manifest V3, Chromium: Chrome, **Яндекс.Браузер**, Edge, Opera,
Brave). Читает цены на Wildberries, Ozon и Яндекс.Маркете на страницах, которые вы **сами** открываете, и переносит
их в приложение Domeo. Всё бесплатно, без платного ИИ: матчер — обычный код, сервер не нужен.

## Принцип (важно)

Расширение **не делает своих запросов** к маркетплейсу. Оно перехватывает JSON-ответы, которые
страница WB/Ozon и так грузит, когда вы просматриваете выдачу/карточку (`inject.js` подменяет
`fetch`/`XHR` в контексте страницы и читает уже пришедшие данные). Поэтому:

- антибот не трогаем — для него это обычный живой пользователь;
- ноль лишнего трафика, ничего не «ломаем».

Автопрогон списка пачкой (чтобы расширение само гоняло поиски) намеренно **не** делаем: это уже
автоматические запросы к маркетплейсу → эскалация антибота и нарушение ToS. База — пассивное чтение
того, что вы открыли; полуавтомат, если понадобится, — только мелкими порциями и под присмотром.

## Файлы

| Файл | Роль |
|---|---|
| `manifest.json` | манифест MV3, матчи на 3 маркетплейса (Wildberries, Ozon, Яндекс.Маркет) |
| `inject.js` | в контексте страницы: **реестр адаптеров** по сайтам, разбор ответов в `{name, price, url, …}` |
| `content.js` | панель (shadow DOM): **строки спеки + «искать»**, авто-обход (**Старт/Стоп**), выбор маркетплейса, связь с приложением |
| `background.js` | service worker: единственный ходит в приложение (127.0.0.1) |
| `popup.html` / `popup.js` | настройка порта приложения и проверка связи |

Мост на стороне API — не в этой папке, а в
`api/src/DomeoSpec.Api/Controllers/ExtensionBridgeController.cs` (+ `Extension/ExtensionBridgeState.cs`);
слушает `127.0.0.1:8777`.

## Установка (Chrome и Яндекс.Браузер)

1. Chrome: открыть `chrome://extensions`. Яндекс: `browser://extensions`.
2. Включить **Режим разработчика** (справа сверху).
3. **Загрузить распакованное расширение** → указать папку `extension/`.
4. Открыть любой маркетплейс (например, Wildberries) — справа снизу появится панель Domeo.

Для коллеги установка такая же — папку можно просто передать. Магазин (и $5 Google) не нужен.

## Как пользоваться (ведёт спека)

1. В приложении Domeo загрузить спецификацию как обычно (том ТХ → разбор в строки). Строки сами
   появятся в панели расширения — через мост (разбор файла делает приложение, не расширение).
2. В панели выбрать маркетплейс и нажать **«искать»** у строки — откроется её поиск на маркетплейсе
   (один клик = один поиск, антибот не трогаем).
3. Расширение прочитает выдачу и покажет варианты с ценами — нажать **«взять»** у подходящего →
   цена уедет в эту строку спеки в Domeo (слот «интернет-цена»; дальше «взять в базовую» как обычно).
4. Нажать «к списку» и так по каждой строке. Готовые маркетплейсы: **Wildberries, Ozon, Яндекс.Маркет**
   (остальные — после доводки парсеров). Без приложения панель показывает товары текущей страницы
   и «Экспорт» в файл.

### Авто-обход (полуавтомат под присмотром)

Кнопка **«Старт авто»** в панели: расширение само идёт по строкам спеки — открывает поиск очередной
позиции, читает выдачу, кладёт в приложение топ-5 вариантов (как предложения интернет-цены), ждёт
паузу и переходит к следующей. Ничего не выбираешь на лету — разбираешь спокойно в приложении
(Себестоимость → «Интернет на дату»: выбор предложения, «взять в базовую»).

Защита — это **не** бот-пачка: пауза между строками **20–40 c** со случайным разбросом, **порциями
по 25** с передышкой **45–90 c** (после передышки идёт сам, до конца спеки — вручную перезапускать не
надо), и **мгновенный стоп** на капче/антиботе или шести пустых выдачах подряд. «Стоп» — в любой
момент, «Старт» продолжит с места. Полного автопрогона всех строк залпом нет намеренно (это
автозапросы → блок и нарушение ToS). Работает на готовых маркетплейсах: **Wildberries, Ozon, Яндекс.Маркет**.

**Параллельно на разных маркетплейсах.** У каждого маркетплейса — свой проход (своя очередь и позиция,
ключ `domeoAuto_<market>`), привязанный к сайту вкладки. Открой Wildberries в одной вкладке, DNS в
другой, Ситилинк в третьей и жми «Старт авто» в каждой — они идут по той же спеке каждый на своём сайте
одновременно, а строка в приложении **копит предложения со всех** (рекомендуемая цена — самое дешёвое из
всех маркетплейсов). Один и тот же сайт в нескольких вкладках сразу не гоняй — это бот-паттерн, за
который блокируют; параллель безопасна именно потому, что каждый сайт видит один спокойный проход.

## Связь с приложением Domeo

```
страница WB/Ozon ──postMessage──► content.js ──chrome.runtime──► background.js ──fetch──► Domeo (127.0.0.1:8777)
```

Два режима:

- **Без приложения (работает сразу).** Кнопка **«Экспорт»** в панели скачивает `domeo-prices.json`
  со всем найденным — потом импортировать в Domeo. Никаких правок приложения не требуется.
- **С приложением (связка).** Мост поднят в API (`ExtensionBridgeController`, слушает
  `127.0.0.1:8777`, только loopback; если порт занят — запуск приложения не падает, мост просто не
  включается). Эндпоинты: `GET /ext/ping`, `GET/POST /ext/spec/current`, `POST /ext/price`,
  `GET /ext/prices`. В панели у каждой цены — выпадающий список строк спеки и кнопка **«→ строку»**;
  цена уезжает в Domeo. Порт настраивается в попапе. Проверено вживую 16.11.2026 (ping/спека/цена
  сквозняком, случайный порт UI не затирается).

Мост — почтовый ящик: расширение шлёт цены (`POST /ext/price`), веб-интерфейс забирает их пачкой
(`GET /ext/prices`, очередь очищается) и раскладывает по строкам. Чтобы в списке «→ строку» была
ваша спека, веб-интерфейс при открытии спецификации шлёт её в мост: `POST /ext/spec/current`
со списком `[{id, name, qty}]`.

## Маркетплейсы: статус адаптеров

Проверено 16.11.2026. **«Готов»** = формат снят на живых данных, парсер написан. **«Нужен твой
браузер»** = в изолированной песочнице (датацентр-IP) сайт упёрся в капчу/блок, формат отсюда не
снять — но в твоём реальном браузере (жилой IP, твоя сессия) он грузится нормально, и адаптер
дописывается по одному живому ответу.

| Сайт | Статус | Как берём данные |
|---|---|---|
| Wildberries | ✅ готов | **DOM** `article[data-nm-id]` (выдача грузится из веб-воркера — JSON не перехватить) |
| Ozon | ✅ готов | **DOM** `.tile-root` (цена — первый `₽`, артикул — из ссылки `/product/…-<id>/`) |
| Яндекс.Маркет | ✅ готов | **DOM** `a[href*="/card/"]` (видимый текст через innerText; SSR-скрипты обходим) |

Снять формат для ⛔: открыть сайт в своём браузере с расширением (при `DEBUG_CAPTURE=true` в
`inject.js`) → в консоли появятся строки `[domeo-capture] …` с образцом ответа → прислать их,
парсер дописывается. Либо через Claude-in-Chrome. Капчи вручную проходишь ты как человек, я — нет.

## Ограничения (честно)

- Пассивное чтение: цена появляется, когда вы открыли товар/выдачу. Это не «залил список — получил
  50 цен в один клик» (см. «Принцип»).
- WB/Ozon периодически меняют вёрстку/API — разбор иногда придётся подновлять.
- Мост слушает только `127.0.0.1` (в сеть не выставлен).
